UNFOLD STUDIOS WEBSITE STARTER

Included:
- index.html: responsive single-page website
- style and layout embedded in index.html
- script.js: portfolio filters and appointment form
- assets/: add your real portfolio images here (optional)

BEFORE PUBLISHING
1. Open script.js and replace 91XXXXXXXXXX with your WhatsApp number in international format (digits only; India example: 919876543210).
2. Replace the six sample portfolio cards in index.html with real project titles, descriptions, and image assets.
3. Add your real email/social links and update the meta description if needed.
4. Test the booking form on mobile and desktop.

BOOKING BEHAVIOUR
The form opens WhatsApp with the appointment details filled in. The visitor still needs to press Send. This starter does not save appointments to a database or automatically confirm time slots. For true availability, calendar sync, email notifications, and automatic confirmations, connect a booking backend/service.

DEPLOY
You can deploy the folder on Vercel, Netlify, or GitHub Pages. For Vercel, import the repository or upload the project folder; no build command is needed for this static version.
